🎯 720 Approach

720 Approach answers: “What should I improve to move toward 720?” It is evidence-driven, not a score guarantee.

  • Subject-wise target gap: Biology 360 + Chemistry 180 + Physics 180.
  • Identify weak chapters/topics from actual attempts.
  • Prioritize repeated mistakes and low-accuracy areas.
  • Protect strong/mastered areas with spaced revision.
  • Use Ranker coverage + Topic-wise Practice + tests as evidence.
  • Track accuracy, speed, negative marking and time loss.
  • Feed the result into the next-best action.

🧠 Skip / Attempt Strategy

This is separate from 720 Approach. It focuses on paper-attempt behaviour.

  • Attempt high-confidence questions first.
  • Do not spend excessive time on a single uncertain question.
  • Mark uncertain questions for revisit instead of forcing them.
  • Track question-level time where CBT history provides it.
  • Compare attempted accuracy with skipped/revisited behaviour.
  • Use post-test evidence to improve future attempt order.
