Security

Security information for the student-facing RankForge app.

LOCAL-FIRST

Local study state

A large part of the app's study state is kept locally on the device/browser.

PROTECTED MODULES

Owner controls

Owner-only modules are separated from normal student workflows. Internal diagnostics are kept out of the student interface.

IMPORTANT

Authentication

A visible security page does not itself create account authentication. Real login, server-side authorization and encrypted backend storage require a properly configured backend.
